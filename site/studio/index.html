How screenplay shortcuts work

Enter after a scene heading or dialogue starts a new paragraph. Tab cycles empty character, scene, action and transition templates; Shift Tab goes back. Existing words stay intact. Use Escape, then Tab to move focus out of the editor.

About page guides

Page numbers follow the current paper size. A + means several pages begin within the same source passage. Page preview shows the exact printed wrapping.

About focus mode

Focus hides the outline and preview. On phones it also hides file and page controls; Commands keeps those actions available. Use Exit focus in the phone header, or Focus again on desktop, to return. Bracket pairing can be switched off above.

Write a screenplay, naturally.

Fountain is plain text. Write a scene heading, leave a blank line, then describe the action. Put a character’s name directly above their dialogue.

INT. LIGHTHOUSE - NIGHT

A light moves across the water.

MARA
(quietly)
Someone is still out there.
Common Fountain marks
Scene
INT. ROOM - DAY or .A FORCED SCENE
Dialogue
A NAME on its own line, followed immediately by speech.
Parenthetical
(under her breath) between the name and speech.
Simultaneous speech
Put ^ after the second character’s name.
Emphasis
*italic*, **bold**, _underline_.
Private note
[[A note that will not print.]]
Omitted passage
/* Keep this out of the PDF. */
Outline
# Act one and = A synopsis do not print.
New page

Writing shortcuts and assistance

The Element menu changes the current line while preserving its words. Ctrl/⌘ Enter starts a new paragraph.

Type @ or start a scene heading to suggest names and locations from your screenplay. Ctrl Space requests suggestions; Escape dismisses them.

Type [[ to get [[|]], with the caret inside. Type closing brackets to move past them. Select text and use Note, B, I or U to wrap it; repeat to remove the marks.

View → Preferences controls bracket pairing and optional screenplay Enter/Tab shortcuts. Escape, then Tab moves focus out of the editor.

Ctrl/⌘ F searches, Ctrl/⌘ Z undoes, and Ctrl/⌘ K opens Commands. Escape closes dialogs.

Saving, privacy and other formats

Open a .fountain or .txt file from File, or drop one onto the writing area. Download Fountain keeps an independent copy outside this browser.

Your draft stays in this browser. Clearing site data removes browser recovery. File → Backup and restore keeps a portable backup.

Ctrl/⌘ S saves to a chosen file where supported, or downloads Fountain. File → Save Fountain as… chooses another file.

Final Draft XML import and export include a compatibility report. Keep your original file: interchange does not preserve every production or layout feature.

PDF uses bundled Courier Prime; unsupported characters are reported before export. Private notes, outlines and omitted passages stay out of the PDF.

Use VoxDown Writer for .vxd stories. File → Adapt to VoxDown creates a separate adaptation.
