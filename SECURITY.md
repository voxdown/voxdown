# Security

VoxDown reads text that others write. A file should never make a tool run code: the renderer escapes every story, keeps only link and image addresses that can't run script, and the playground sends nothing anywhere.

If you find a way around that, or any other security problem, please report it privately with **Report a vulnerability** on the repository’s [Security tab](https://github.com/voxdown/voxdown/security/advisories/new), not in a public issue. We will answer within a week.

Fixes go into the latest release of each package.
