# Try the current VoxDown Studio

Open the running local app at http://localhost:5173/studio/. Work remains in the browser;
no accounts or server are involved. Keep a downloaded Fountain file or Studio backup as an
independent copy. Browser recovery and an installed offline copy are conveniences, not backups.

## Start writing

Use Help → Guided practice for six short exercises in a separate practice
buffer. Use Help → Try a short screenplay for an editable example. Optional screenplay Enter/Tab behavior lives
in View → Preferences; ordinary text editing remains available. Select a phrase and use Bold,
Italic, Underline or Note; the Fountain text remains authoritative and Undo restores it.

On a phone, Focus gives the text more room; Exit focus is always in the header. File groups
Open, Download and recovery tools. Commands remains available in Focus. On a tablet, Expand
preview makes the screenplay page readable; Return to writing or Escape restores the editor.
Preview actions (•••) → Go to page source takes you from the page to its source line.

On desktop, drag the dividers to resize Scenes and preview. Focus a divider and use arrow
keys to resize it with the keyboard; double-click to reset. Close Scenes with its × button,
then reopen it from the Scenes toolbar button or View menu. View also shows current panel
and Focus states. Tools groups revision, planning and inspection commands.

## Revise a scene

Open Scene cards and rearrangement through Commands. Add a synopsis or preview a move within
its section, then apply and Undo it. Try Character dialogue → expand a character → Edit this
speech. Character and location renaming show affected source before committing. Scoped find
and replace can limit a literal replacement to dialogue, action, a scene or a selection.

## Prepare a handoff

Export PDF uses the same pagination as the preview. Actor sides PDF includes the selected
character's complete scenes. Rehearsal cue cards let you reveal speeches at your own pace.
Scene and cast breakdown produces an explicit spreadsheet-safe CSV. Number scenes preserves
existing labels by default. FDX import/export explains its supported subset and conversion
losses; native Final Draft acceptance is still a manual gate.

Adapt screenplay to VoxDown prepares a separate .vxd file and validates it with the VoxDown
parser. Check the cast and narration choices, and acknowledge sequential delivery if your
screenplay contains simultaneous dialogue. Private comments and title/contact metadata are
excluded from public handoffs. Ambiguous unclosed/nested omissions block unsafe conversion.

## Protect a revision

File → Recovery and snapshots contains drafts and named snapshots; restoring opens a separate draft with fresh undo
history. Compare with local Fountain file is read-only. Download a Studio backup for portable
recovery. Where the browser offers direct local-file access, Save detects external changes;
other browsers retain ordinary Fountain download. Prepare offline is explicit and scoped to
Studio. It includes first-use export assets and does not cache your screenplay.

## Acceptance still needed

Physical iPhone Brave/Safari behavior, real IME keyboards, VoiceOver/NVDA, native OS file
permissions, native Final Draft import and printed-page review have not been certified by
emulated browser checks. Unsupported PDF glyphs/shaping are reported; the source is retained.
