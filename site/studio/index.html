Your writing space

These settings change your workspace, not your screenplay or its printed pages.

Enter after a scene heading or dialogue starts a new paragraph. Tab cycles empty character, scene, action and transition templates; Shift Tab goes back. Existing words stay intact. Use Escape, then Tab to move focus out of the editor.

Page numbers follow the current paper size. A + means several pages begin within the same source passage. Page preview shows the exact printed wrapping.

Focus hides the outline and preview. Use Focus again (in Commands on phones) to return. Bracket pairing can be switched off above.

Write a screenplay, naturally.

Fountain is plain text. Leave a blank line between paragraphs. Studio displays the margins; your file keeps the words you type.

The Element menu changes the current line while preserving its words. Ctrl/⌘ Enter starts a separated paragraph. Preferences can enable screenplay Enter/Tab assistance; it starts switched off. Type @ or start a scene heading to suggest names and locations already in your screenplay. Ctrl Space requests suggestions; Escape dismisses them.

Type [[ to get [[|]], with the caret inside. Typing the closing brackets moves past the generated ones. Backspace removes an empty pair, one layer at a time. Select text and use Note, B, I, or U to wrap it; repeat to remove the marks. Pasted text and ordinary quotation marks are left as typed. Change pairing in Preferences (also available from Commands).
