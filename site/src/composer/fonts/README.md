# Composer Mono

`recursive-mono-latin.woff2` is a static instance of Recursive (Latin, from
`@fontsource-variable/recursive` 5.3.0's full-axes file): Mono 1, Casual 0, upright, Cursive 0.5,
with the weight axis kept from 300 to 800. It is the editor's font, so ABC lines up in columns
(Edit › Tune book › Line up bars). Recursive is © 2019 The Recursive Project Authors, under the SIL
Open Font License 1.1 (`OFL.txt`). Made with fontTools:

    instancer.instantiateVariableFont(font, {"MONO": 1, "CASL": 0, "slnt": 0, "CRSV": 0.5, "wght": (300, 800)})
