    How it’s made
    
      
      
        
    1. lines() turns the story into the lines a listener hears, each with its speaker and direction.
      2. 
        
    2. Each line goes to its character’s voice, the direction as a tag the voice performs.
      3. 
        
    3. Sounds and pauses go between the lines, and the page lights each line as it plays.
      4. 
      
    
      
    import { lines, parse } from "voxdown";

for (const line of lines(parse(story))) {
  const voice = voices[line.speaker];
  const text = line.direction
    ? `[${line.direction}] ${line.text}`
    : line.text;

}
